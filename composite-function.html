ฟังก์ชัน · บทที่ 01

ฟังก์ชันประกอบคืออะไร อธิบายด้วยตัวเลขจริง

ฟังก์ชันประกอบ คือการเอาคำตอบของฟังก์ชันหนึ่ง ไปเป็นข้อมูลเข้าของอีกฟังก์ชันหนึ่ง เขียนว่า (f∘g)(x) = f( g(x) ) อ่านจากขวาไปซ้าย คือทำ g ก่อน แล้วค่อยเอาผลไปใส่ f

เข้าใจด้วยเลขก่อน ยังไม่ต้องมีตัวแปร

ให้ f(x) = 3x และ g(x) = x + 2 แล้วหา (f∘g)(1)

แทน x = 1 ทีละขั้น

  1. (f∘g)(1) = f( g(1) )
  2. g(1) = 1 + 2 = 3
  3. = f(3)
  4. = 3 × 3 = 9

เห็นไหมว่า g ทำงานก่อน ได้ 3 แล้ว 3 ตัวนี้ถึงเดินเข้าไปหา f ต่อ

ทีนี้ทำแบบเป็นสูตร

หา (f∘g)(x) เมื่อ f(x) = 3x และ g(x) = x + 2

  1. (f∘g)(x) = f( g(x) )
  2. = f( x + 2 )
  3. = 3( x + 2 )
  4. = 3x + 6
เช็กด้วย x = 1: 3(1) + 6 = 9 ✓ ตรงกับที่คำนวณข้างบน

เคล็ดลับ: ขั้นที่ 2 คือหัวใจ ให้เอา g(x) ทั้งก้อน ไปแทนตรงที่ f มีตัว x อยู่ ถ้า f มี x หลายที่ ก็แทนทุกที่

พื้นที่โฆษณา — ใส่โค้ด AdSense ตรงนี้ทีหลัง

จุดที่คนพลาดบ่อยที่สุด

(f∘g) กับ (g∘f) ไม่เท่ากัน

ใช้ f และ g ชุดเดิม แต่สลับลำดับ ผลต่างกันทันที

(f∘g)(x) = f(x + 2) = 3(x + 2) = 3x + 6
(g∘f)(x) = g(3x) = 3x + 2

แทน x = 1: ได้ 9 กับ 5 — คนละคำตอบเลย

ตัวอย่างที่ยากขึ้น มีกำลังสอง

f(x) = 2x + 1 , g(x) = x² − 3 หา (f∘g)(x)

  1. (f∘g)(x) = f( x² − 3 )
  2. = 2( x² − 3 ) + 1
  3. = 2x² − 6 + 1
  4. = 2x² − 5
เช็กด้วย x = 2:
g(2) = 4 − 3 = 1 → f(1) = 2(1) + 1 = 3
สูตร: 2(2)² − 5 = 8 − 5 = 3 ✓

แบบฝึกหัด กดดูเฉลยได้

ข้อ 1 — f(x) = x + 5 , g(x) = 2x หา (f∘g)(x)

f( 2x ) = 2x + 5    [เช็ก x=3: g=6, f(6)=11 ✓]

ข้อ 2 — f(x) = x² , g(x) = x − 1 หา (f∘g)(x)

f( x − 1 ) = (x − 1)² = x² − 2x + 1    [เช็ก x=4: g=3, f(3)=9 ✓]

ข้อ 3 — f(x) = 2x − 1 , g(x) = x² + 3 หา (g∘f)(x)

ระวัง ข้อนี้สลับลำดับ
g( 2x − 1 ) = (2x − 1)² + 3 = 4x² − 4x + 4    [เช็ก x=1: f(1)=1, g(1)=4 ✓]
