โดเมนกับเรนจ์ ต่างกันยังไง

โดเมน คือค่า x ทั้งหมดที่ใส่เข้าไปได้ — ดูตามแนวนอน
เรนจ์ คือค่า y ทั้งหมดที่ออกมาได้ — ดูตามแนวตั้ง

วิธีจำง่ายๆ: โดเมนคือ "อะไรใส่ได้บ้าง" เรนจ์คือ "อะไรออกมาได้บ้าง" เรียงตามลำดับ x ก่อน y เหมือนเวลาเขียนพิกัด (x, y)

ตัวอย่างที่ 1 — f(x) = x²

หาโดเมนและเรนจ์

  1. ใส่ x อะไรก็ได้ ยกกำลังสองได้หมด
  2. โดเมน = จำนวนจริงทั้งหมด
  3. แต่ยกกำลังสองแล้วติดลบไม่ได้
  4. เรนจ์ = y ≥ 0
ลองแทนดู: f(3) = 9, f(−3) = 9, f(0) = 0
ไม่ว่าใส่อะไร ผลลัพธ์ไม่เคยติดลบ
พื้นที่โฆษณา — ใส่โค้ด AdSense ตรงนี้ทีหลัง

ตัวอย่างที่ 2 — ติดรากที่สอง

รากที่สองของจำนวนติดลบ ไม่มีคำตอบในจำนวนจริง ตรงนี้คือที่มาของข้อจำกัด

f(x) = √(x − 4)

  1. ในรากต้องไม่ติดลบ → x − 4 ≥ 0
  2. x ≥ 4
  3. โดเมน = x ≥ 4
  4. รากที่สองให้ผลไม่ติดลบเสมอ → เรนจ์ = y ≥ 0
เช็ก: f(4) = √0 = 0 ✓ ใส่ได้
f(3) = √(−1) ✗ ไม่มีคำตอบ ตรงกับที่บอกว่า x ต้อง ≥ 4

ตัวอย่างที่ 3 — เศษส่วน

ตัวส่วนเป็นศูนย์ไม่ได้ ตรงนี้คือข้อจำกัดของโดเมน

f(x) = 1 / (x − 2)

  1. ตัวส่วนห้ามเป็น 0 → x − 2 ≠ 0
  2. x ≠ 2
  3. โดเมน = จำนวนจริงทุกตัว ยกเว้น 2
  4. เศษเป็น 1 ตลอด หารยังไงก็ไม่ได้ 0 → เรนจ์ = y ≠ 0

จุดที่คนพลาดบ่อย

สลับแกนกัน

เวลาดูกราฟ คนมักเผลอมองเรนจ์เป็นแนวนอน วิธีกันพลาดคือลากเส้นในหัวก่อน

โดเมน → กวาดสายตาซ้าย-ขวา ดูว่ากราฟกินพื้นที่แกน x ตรงไหนบ้าง
เรนจ์   → กวาดสายตาบน-ล่าง ดูว่ากราฟกินพื้นที่แกน y ตรงไหนบ้าง

✎ จุดที่มุกต้องเขียนเอง
ลบกล่องนี้ทิ้ง แล้วเขียนแทนว่า ตอนแรกมุกงงตรงไหน จำได้ยังไงถึงเลิกงง แค่ 2–3 บรรทัดพอ ตรงนี้คือส่วนที่ทำให้เว็บผ่านการตรวจของ AdSense

แบบฝึกหัด กดดูเฉลยได้

ข้อ 1 — หาโดเมนของ f(x) = √(x + 3)

x + 3 ≥ 0 → x ≥ −3
[เช็ก x=−3: √0 = 0 ✓ / x=−4: √(−1) ✗]

ข้อ 2 — หาโดเมนของ f(x) = 1 / (x + 5)

x + 5 ≠ 0 → x ≠ −5
โดเมน = จำนวนจริงทุกตัว ยกเว้น −5

ข้อ 3 — หาเรนจ์ของ f(x) = x² + 1

x² ≥ 0 เสมอ → x² + 1 ≥ 1
เรนจ์ = y ≥ 1    [ต่ำสุดตอน x=0: f(0)=1]
