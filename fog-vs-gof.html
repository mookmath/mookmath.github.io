ฟังก์ชัน · บทที่ 04

ทำไม (f∘g) ไม่เท่ากับ (g∘f)

เพราะฟังก์ชันประกอบคือการทำงานตามลำดับ สลับลำดับก็ได้ผลคนละอย่าง เหมือนใส่ถุงเท้าแล้วใส่รองเท้า ต่างจากใส่รองเท้าแล้วใส่ถุงเท้า

พิสูจน์ด้วยเลข 2 บรรทัด

ให้ f(x) = x + 3 และ g(x) = 2x

ทำ g ก่อน แล้วค่อย f

  1. (f∘g)(x) = f( g(x) )
  2. = f( 2x )
  3. = 2x + 3

ทำ f ก่อน แล้วค่อย g

  1. (g∘f)(x) = g( f(x) )
  2. = g( x + 3 )
  3. = 2( x + 3 ) = 2x + 6
แทน x = 1 เทียบกัน:
(f∘g)(1) = 2(1) + 3 = 5
(g∘f)(1) = 2(1) + 6 = 8
ต่างกัน 3 ชัดเจน

เหตุผลง่ายๆ: กรณีแรก บวก 3 ทีหลัง เลข 3 เลยไม่โดนคูณ กรณีที่สอง บวก 3 ก่อน เลข 3 เลยโดนคูณ 2 ด้วย กลายเป็น 6

พื้นที่โฆษณา — ใส่โค้ด AdSense ตรงนี้ทีหลัง

แล้วมีกรณีที่เท่ากันไหม

มี แต่พิเศษมาก คือเมื่อ g เป็นฟังก์ชันผกผันของ f พอดี ตอนนั้นจะได้ x กลับมาทั้งสองทาง

f(x) = 2x + 1 และ f⁻¹(x) = (x − 1) / 2

  1. (f∘f⁻¹)(x) = f( (x − 1)/2 )
  2. = 2 · (x − 1)/2 + 1
  3. = (x − 1) + 1 = x
  4. (f⁻¹∘f)(x) = f⁻¹( 2x + 1 )
  5. = (2x + 1 − 1) / 2 = x
ได้ x เท่ากันทั้งสองทาง — นี่คือวิธีพิสูจน์ว่าสองฟังก์ชันเป็นผกผันกันจริง

จุดที่คนพลาดบ่อย

อ่านผิดทิศ

สัญลักษณ์ (f∘g) เขียน f ก่อน แต่ต้องทำ g ก่อน — ตรงข้ามกับที่ตาเห็น

(f∘g)(x) = f( g(x) )
     ↑ อ่านจากขวาไปซ้าย

วิธีจำ: ตัวที่ติดกับ (x) มากที่สุด คือตัวที่ทำงานก่อน

✎ จุดที่มุกต้องเขียนเอง
ลบกล่องนี้ทิ้ง แล้วเขียนแทนว่า ตอนแรกมุกงงตรงไหน จำได้ยังไงถึงเลิกงง แค่ 2–3 บรรทัดพอ ตรงนี้คือส่วนที่ทำให้เว็บผ่านการตรวจของ AdSense

แบบฝึกหัด กดดูเฉลยได้

ข้อ 1 — f(x) = x − 4 , g(x) = 3x หา (f∘g)(x) และ (g∘f)(x)

(f∘g)(x) = f(3x) = 3x − 4
(g∘f)(x) = g(x − 4) = 3(x − 4) = 3x − 12
[เช็ก x=2: ได้ 2 กับ −6 — ต่างกัน]

ข้อ 2 — f(x) = x² , g(x) = x + 1 หา (f∘g)(2)

g(2) = 3 → f(3) = 9
ลองสลับดู: f(2) = 4 → g(4) = 5 — ได้ 9 กับ 5 ต่างกัน

ข้อ 3 — f(x) = 3x และ g(x) = x/3 เป็นผกผันกันหรือไม่

(f∘g)(x) = f(x/3) = 3 · x/3 = x
(g∘f)(x) = g(3x) = 3x/3 = x
ได้ x ทั้งคู่ → เป็นผกผันกัน ✓
