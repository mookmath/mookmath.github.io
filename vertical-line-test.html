ฟังก์ชัน · บทที่ 05

เช็กว่าเป็นฟังก์ชันไหม ด้วยเส้นแนวตั้ง

ลากเส้นตรงแนวตั้งผ่านกราฟ ถ้าตัดกราฟได้จุดเดียวทุกตำแหน่ง แปลว่าเป็นฟังก์ชัน ถ้ามีสักที่ที่ตัดได้ 2 จุดขึ้นไป แปลว่าไม่ใช่ฟังก์ชัน

เหตุผลอยู่ที่นิยาม: ฟังก์ชันคือ x หนึ่งค่า ต้องให้ y ได้ค่าเดียวเท่านั้น ถ้าเส้นแนวตั้งตัดได้ 2 จุด แปลว่า x ตัวนั้นให้ y ได้ 2 ค่า ผิดนิยามทันที

ตัวอย่างที่ผ่าน — y = x²

ลองแทนค่าดู

  1. x = 2 → y = 4  (ค่าเดียว)
  2. x = −2 → y = 4  (ค่าเดียว)
  3. x = 0 → y = 0  (ค่าเดียว)
  4. ทุก x ให้ y ค่าเดียว → เป็นฟังก์ชัน ✓
สังเกต: y ซ้ำกันได้ (x=2 กับ x=−2 ให้ 4 เหมือนกัน) ไม่ผิดกติกา
ที่ห้ามคือ x ตัวเดียวให้ y หลายค่า
พื้นที่โฆษณา — ใส่โค้ด AdSense ตรงนี้ทีหลัง

ตัวอย่างที่ไม่ผ่าน — x = y²

ลองแทน x = 4

  1. 4 = y²
  2. y = 2 หรือ y = −2
  3. x ตัวเดียวให้ y สองค่า
  4. ไม่เป็นฟังก์ชัน ✗
บนกราฟ: ลากเส้นแนวตั้งที่ x = 4 จะตัดกราฟที่จุด (4, 2) และ (4, −2) — สองจุด

วงกลมก็ไม่ผ่าน

x² + y² = 25 ลองแทน x = 3

  1. 9 + y² = 25
  2. y² = 16
  3. y = 4 หรือ y = −4
  4. ไม่เป็นฟังก์ชัน ✗

วงกลมทุกวง สี่เหลี่ยมทุกรูป และวงรี ล้วนไม่เป็นฟังก์ชัน เพราะเส้นแนวตั้งตัดได้ 2 จุดเสมอ

เส้นแนวนอน ใช้เช็กอีกอย่าง

พอรู้ว่าเป็นฟังก์ชันแล้ว ถ้าอยากรู้ต่อว่ามีผกผันไหม ให้ลากเส้นแนวนอนแทน

อย่าสับสนสองเส้นนี้

เส้นแนวตั้ง  → เช็กว่า "เป็นฟังก์ชันไหม"
เส้นแนวนอน → เช็กว่า "มีผกผันไหม" (หนึ่งต่อหนึ่ง)

y = x² ผ่านแนวตั้ง ✓ แต่ไม่ผ่านแนวนอน ✗
เพราะเส้น y = 4 ตัดกราฟที่ x = 2 และ x = −2

✎ จุดที่มุกต้องเขียนเอง
ลบกล่องนี้ทิ้ง แล้วเขียนแทนว่า ตอนแรกมุกงงตรงไหน จำได้ยังไงถึงเลิกงง แค่ 2–3 บรรทัดพอ ตรงนี้คือส่วนที่ทำให้เว็บผ่านการตรวจของ AdSense

แบบฝึกหัด กดดูเฉลยได้

ข้อ 1 — y = 3x + 1 เป็นฟังก์ชันหรือไม่

เป็น ✓ เส้นตรงเฉียง เส้นแนวตั้งตัดได้จุดเดียวเสมอ
[x=2 → y=7 ค่าเดียว]

ข้อ 2 — x = 5 (เส้นตรงแนวตั้ง) เป็นฟังก์ชันหรือไม่

ไม่เป็น ✗ ที่ x = 5 มี y ได้ทุกค่า — ไม่จำกัดเลย
เส้นแนวตั้งทับกันพอดี ตัดได้เป็นล้านจุด

ข้อ 3 — y = x³ ผ่านการทดสอบเส้นแนวนอนไหม

ผ่าน ✓ ยกกำลังสามรักษาเครื่องหมาย
2³ = 8 , (−2)³ = −8 — ไม่ซ้ำกัน → มีผกผัน คือ f⁻¹(x) = ∛x
