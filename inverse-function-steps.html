ฟังก์ชัน · บทที่ 02

หาฟังก์ชันผกผัน 3 ขั้นตอน

ฟังก์ชันผกผัน คือฟังก์ชันที่ทำงานย้อนกลับ ถ้า f พา 4 ไปเป็น 11 แล้ว f⁻¹ ก็พา 11 กลับมาเป็น 4 วิธีหาใช้ 3 ขั้นเสมอ: เปลี่ยน f(x) เป็น y → สลับ x กับ y → จัดรูปหา y

ตัวอย่างที่ 1 — f(x) = 2x + 3

ไล่ทีละขั้น

  1. y = 2x + 3
  2. x = 2y + 3  ← สลับ x กับ y
  3. x − 3 = 2y
  4. y = (x − 3) / 2
  5. f⁻¹(x) = (x − 3) / 2
เช็กด้วย x = 4:
f(4) = 2(4) + 3 = 11
f⁻¹(11) = (11 − 3) / 2 = 8 / 2 = 4 ✓ กลับมาที่เดิม

วิธีเช็กว่าทำถูกไหม ใช้ได้ทุกข้อ: เอาเลขอะไรก็ได้ใส่ f แล้วเอาคำตอบไปใส่ f⁻¹ ถ้าได้เลขเดิมกลับมา แปลว่าถูก

พื้นที่โฆษณา — ใส่โค้ด AdSense ตรงนี้ทีหลัง

ตัวอย่างที่ 2 — มีเศษส่วน

f(x) = (x + 1) / 3

  1. y = (x + 1) / 3
  2. x = (y + 1) / 3
  3. 3x = y + 1
  4. y = 3x − 1
  5. f⁻¹(x) = 3x − 1
เช็กด้วย x = 5:
f(5) = (5 + 1) / 3 = 2
f⁻¹(2) = 3(2) − 1 = 5 ✓

สังเกตว่า f หาร 3 ส่วน f⁻¹ คูณ 3 — ผกผันคือการทำย้อนกลับทุกอย่าง คูณกลายเป็นหาร บวกกลายเป็นลบ

จุดที่คนพลาดบ่อย

f⁻¹(x) ไม่ใช่ 1 / f(x)

เลข −1 ข้างบนนี้ไม่ใช่เลขยกกำลัง มันเป็นแค่สัญลักษณ์ที่แปลว่า "ผกผัน"

f(x) = 2x + 3
f⁻¹(x) = (x − 3) / 2  ✓ ถูก
1 / (2x + 3)  ✗ ผิด คนละเรื่องเลย

✎

ไม่ใช่ทุกฟังก์ชันจะมีผกผัน

ฟังก์ชันจะมีผกผันได้ ต้องเป็นแบบ หนึ่งต่อหนึ่ง คือ y แต่ละค่ามาจาก x ได้ค่าเดียว

f(x) = x²   ไม่มีผกผัน
เพราะ f(2) = 4 และ f(−2) = 4
ถ้าถามว่า 4 กลับไปเป็นอะไร ตอบไม่ได้ว่า 2 หรือ −2

แต่ถ้าจำกัดโดเมนให้ x ≥ 0 ก็จะมีผกผันได้ คือ f⁻¹(x) = √x

แบบฝึกหัด กดดูเฉลยได้

ข้อ 1 — f(x) = x − 7

y = x − 7 → x = y − 7 → y = x + 7
f⁻¹(x) = x + 7    [เช็ก x=10: f=3, f⁻¹(3)=10 ✓]

ข้อ 2 — f(x) = 5x

y = 5x → x = 5y → y = x / 5
f⁻¹(x) = x / 5    [เช็ก x=3: f=15, f⁻¹(15)=3 ✓]

ข้อ 3 — f(x) = 4x − 1

y = 4x − 1 → x = 4y − 1 → x + 1 = 4y → y = (x + 1) / 4
f⁻¹(x) = (x + 1) / 4    [เช็ก x=2: f=7, f⁻¹(7)=8/4=2 ✓]
