อธิบายด้วยตัวเลขจริง

เว็บนี้ไม่บอกแค่ว่า “คำตอบคือ” แต่จะไล่ให้ดูทุกบรรทัดว่าเลขแต่ละตัวมาจากไหน แบบที่อ่านแล้วทำตามเองได้

ตัวอย่าง — หา (f∘g)(x) เมื่อ f(x) = 2x + 1 และ g(x) = x² − 3

  1. (f∘g)(x) = f( g(x) )
  2. = f( x² − 3 )
  3. = 2( x² − 3 ) + 1
  4. = 2x² − 6 + 1
  5. = 2x² − 5
ลองแทน x = 2 เช็ก:
g(2) = 4 − 3 = 1 → f(1) = 2(1) + 1 = 3
สูตรที่ได้: 2(2)² − 5 = 8 − 5 = 3 ✓ ตรงกัน

บทความทั้งหมด

กำลังทยอยเขียน สัปดาห์ละ 1–2 เรื่อง

  • 01ฟังก์ชันประกอบคืออะไร เข้าใจใน 5 นาทีพร้อมตัวอย่างเลข 4 ข้อ และจุดที่คนสลับ f กับ g บ่อย
  • 02หาฟังก์ชันผกผัน 3 ขั้นตอนสลับ x กับ y แล้วจัดรูป ทำไมต้องทำแบบนั้น
  • 03โดเมนกับเรนจ์ ดูจากกราฟยังไงแยกให้ชัดว่าอันไหนแกน x อันไหนแกน y
  • 04ทำไม (f∘g) ไม่เท่ากับ (g∘f)พิสูจน์ด้วยตัวเลขจริง 2 บรรทัด
  • 05เช็กว่าเป็นฟังก์ชันหรือไม่ ด้วยเส้นแนวตั้งพร้อมกราฟที่ผ่านและไม่ผ่าน
